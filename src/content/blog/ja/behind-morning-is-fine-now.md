アルバムは六曲かけて守ってきたものを手放して終わります。

## この曲が生まれた場面

「決めた わけじゃない / 諦めた わけでもない / ただ カーテンを / 開けてしまった」 — **決定は体が先にしました。** 光はもう入り、戻せないので「それで いい」になります。

2曲目がここで裏返ります:「寝るのを やめる / 負けでも いい / 今日は そういう日 / それだけのこと」。「寝たら負けみたいで」眠れなかった人が、今度は**負けでもいいと言いながら**寝ません。同じ行動、逆の理由。

サビがこのアルバムの一文です:「もう 朝でいい / 夜が 終わった / もう 朝でいい / **私は 終わってない**」。

コーヒーを淹れ、朝の動きをします:「体は 覚えている」。そしてタイトルの時刻を何でもなかったと片づけます:「四時は 過ぎた / 過ぎてしまえば / 何でも なかった / 毎日 そうだ」。**そして最後の行が「明日も たぶん 四時」です。**

## サウンドノート

**1曲目の空白に戻ります** — パッド一つとベース。ただし最後の行で**リバーブが閉じずに開きます。** Aマイナー。

## 一行

> もう 朝でいい / 夜が 終わった / もう 朝でいい / 私は 終わってない

前作は電気を消し、残響を切って閉じました。この作品はカーテンを開け、響きを残します。**AFTERは閉じて終わり、Originalは開いて終わります** — そして「明日も たぶん 四時」なので、そもそも閉じません。
