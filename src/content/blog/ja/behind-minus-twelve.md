十二を引いて、十二を足す。それがこの曲の全部です。

## この曲が生まれた場面

「十二 引けば / そっちの時間 / 足せば 私」。覚えようとして覚えたのではありません:「覚えたくて / 覚えたんじゃない / 何度も やったら / 体が 覚えた」。**努力ではなく反復でした。** 最初は指を折って数え、今は見た瞬間に分かります。

そして慣れた代償がこの曲の要点です:「それだけのこと / なのに 遠い / 数字が 遠い」。**距離に慣れても距離は縮みません。**

最後のAメロは公平な時刻を探して、悪い時刻だけを見つけます:「真ん中は どこ / 六時間ずつ / どっちも 無理を / してる時間」。

## サウンドノート

**指を鳴らす音がリズムです** — 短く規則的なフィンガースナップ。サブベースは短く切り、ローズの一節が同じ場所で繰り返します。数える曲なので、編曲も数えます。

## 一行

> それだけのこと / なのに 遠い / 数字が 遠い

アルバムで最も短く、最も動かない曲です。意図的です — 場面ではなく計算だからです。
