十一枚目にして、私が先です。

## この曲が生まれた場面

挨拶からして時間に合いません:「「おやすみ」って 言うと / 「いってらっしゃい」みたいだ」。

そして「先に 寝るね / 初めて 言う」。**前作では、いつも何かが私より先でした** — スマホの充電が先に切れ(「私より 先に / これが 終わる」)、空が先に起きました(「空が 先に起きる」)。この曲がその二つを呼び出して裏返します:「充電が 先に 切れた / 空が 先に 起きた / 今日は 私が / 先に 終わる」。

閉じません:「そっちの昼は 続く / 続いてて いい / 私は ここで 終わる」。そして誰かが入れ替わりで起きているので「だから この夜は / 終わらない」。

最後の動作が前作にぴたりと答えます。あの作品は「カーテンを / 開けてしまった」で終わりました。ここでは**閉めます**:「カーテンを 閉める / 今度は 閉める方だ / 明るくなる前に / 先に 寝る」。

## サウンドノート

**1曲目の編成に戻ります** — ドラムは完全に抜け、ローズとサブベースだけ、ハーモニーが薄くなり最後に一つの声だけが残ります。そして**最後の行で残響が閉じずに開きます。**

## 一行

> カーテンを 閉める / 今度は 閉める方だ

AFTERラインはいつも何かを閉じて終わりました — 電気を消し、部屋を空にして。この作品はカーテンを閉め、音は開いたままにします。ここで終わるのは私だけで、そっちの昼は続くからです。**それは閉じられません。**
