アルバムは、始まりに持っていたものを取り上げて閉じます。

## この曲が生まれた場面

鍵はポストに入れます。最後にもう一度部屋を見ます:「何も 忘れてない / 確認は した / もう 戻らない / 戻る理由が ない」。

そしてアルバム全体が歩いてきた行が来ます:「ずっと 消せなかった / 何年も ずっと / **今夜は / 消せる**」。サビはそれを勝利にしません —「Turn it off / それだけ / 何年も かかった / **それだけのことに**」。その程度のことに何年もかかりました。

電気を消すと、部屋は入った日の部屋になります:「暗くなった部屋は / 入った日と 同じ / 何も なくて / 広くて / ここから 始めて / ここで 終わる / **それで いい / それが いい**」。1曲目の「それで いいと 思う / それが いいと 思う」が短くなって戻ります。**夜の始まりに自分をなだめていた言葉が、終わりでは断定になります。**

そして最後の行がアルバムを閉じます:「ドアを 閉める / 音が しない / **響く部屋が / もう ない**」。

## サウンドノート

**ドラムが抜け、1曲目が立っていた位置に戻ります** — ローズとサブベースだけです。そして最後で**リバーブの尾をフェードせず切りました。** 1曲目で最も大きく響いた部屋が、ここで音そのものを失います。

## 一行

> ドアを 閉める / 音が しない / 響く部屋が / もう ない

このアルバムで「響」はちょうど二回だけ出ます。1曲目の二行目「歩くと 響く」と、7曲目の最後「響く部屋が / もう ない」です。だから尾をフェードせず切りました — 電気を消したからです。

前作の2曲目が「Don't Turn the Light On」でした。この作品は「Turn It Off」で終わります。AFTERラインの二枚で、灯りがタイトルに二度出て、方向が反対です。
