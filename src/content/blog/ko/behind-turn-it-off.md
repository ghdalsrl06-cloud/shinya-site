앨범은 시작할 때 갖고 있던 것을 거둬들이며 닫힙니다.

## 이 곡이 태어난 장면

열쇠는 우편함에 넣습니다. 마지막으로 방을 한 번 더 봅니다: 「아무것도 안 잊었다 / 확인은 했다 / 이제 돌아오지 않는다 / 돌아올 이유가 없다」.

그리고 앨범 전체가 걸어온 줄이 나옵니다: 「계속 끄지 못했다 / 몇 년이나 계속 / **오늘 밤은 / 끌 수 있다**」. 후렴은 그걸 승리로 만들지 않습니다 — 「Turn it off / 그것뿐 / 몇 년이 걸렸다 / **그것뿐인 일에**」. 그 사소한 일에 몇 년이 걸렸습니다.

불을 끄자 방은 들어온 날의 방이 됩니다: 「어두워진 방은 / 들어온 날과 같다 / 아무것도 없고 / 넓고 / 여기서 시작해서 / 여기서 끝난다 / **그러면 됐다 / 그게 낫다**」. 1번의 「그래도 된다고 생각한다 / 그게 낫다고 생각한다」가 짧아져 돌아옵니다. **밤을 시작할 때 자기를 달래던 말이, 끝에서는 단정이 됩니다.**

그리고 마지막 줄이 앨범을 닫습니다: 「문을 닫는다 / 소리가 나지 않는다 / **울리는 방이 / 이제 없다**」.

## 사운드 노트

**드럼이 빠지고 1번이 서 있던 자리로 돌아갑니다** — 로즈와 서브베이스만 남습니다. 그리고 맨 끝에서 **리버브 꼬리를 페이드하지 않고 잘라 냈습니다.** 1번에서 가장 크게 울리던 방이 여기서 소리 자체를 잃습니다.

## 한 줄

> ドアを 閉める / 音が しない / 響く部屋が / もう ない — 문을 닫는다 / 소리가 나지 않는다 / 울리는 방이 / 이제 없다

이 앨범에서 「響」(울림)은 정확히 두 번 나옵니다. 1번의 두 번째 줄 「걸으면 울린다」와 7번의 마지막 줄 「울리는 방이 / 이제 없다」입니다. 그래서 꼬리를 페이드하지 않고 잘라 냈습니다 — 불을 껐으니까요.

직전 앨범 2번이 「Don't Turn the Light On」(불은 켜지 마)이었고, 이 앨범은 「Turn It Off」(불을 끈다)로 끝납니다. AFTER 라인 두 장에서 불이 제목으로 두 번 나오고 방향이 반대입니다.
